- 日期：2026-08-30
- 任务：验证 2.86×/100% → 3×/99% → 4×/99% → 5×/99% 边界是否成立，并继续向高倍率推进
- 语料：`_core_0804_0818.txt`（345,347,877 字节 / 93,544 段 / 979,069 唯一句）

## 一、背景与验证目标

本测试围绕一个核心问题：**AI 长期记忆如何在尽可能保留信息与结构的前提下提高信息密度**。

验证目标：2.86×/100% → 3×/99% → 4×/99% → 5×/99% 边界是否成立，高倍率区间是否仍能保持字符级无损。

## 二、关键事实（为什么「删句子」路线走不通）

此前实测（判据 295 条因果痕迹）：

| R | 存储率 | 倍率 | 痕迹≥99% | 机制 |
|---|---|---|---|---|
| 1.0 | 35.0% | 2.86× | 100% ✅ | 纯去重（零删除） |
| 0.95 | 34.3% | 2.92× | 95.59% ❌ | 删 5% 唯一句 |
| 0.75 | 31.8% | 3.14× | 89.15% ❌ | 删 25% |
| 0.50 | 25.8% | 3.88× | 86.44% ❌ | 删 50% |
| 0.20 | 6.6% | 15.1× | 29.49% ❌ | 删 80% |

**结论**：任何「删内容」都立即破 99% 线——2.92× 就掉到 95.59%。删除策略与痕迹重要性反向（高频≠冗余三度实锤）。3×~5× 不可能靠删除达成。

## 三、新机制：存在/访问路径解耦（零删除无损）

设计（编码端零 TARGETS、纯通用词频）：

1. **存在层**：唯一句表 S 全部保留（979,069 句零删除）——痕迹 100% 的物理基础
2. **表达层**：高频词字典化（词→整数 ID，varint 编码；\x00 转义防二进制冲突）
3. **访问层**：P 位置映射 varint XOR 差分紧凑编码（28.2MB JSON → 紧凑二进制）
4. **无损校验**：展开后与原文逐字比对，979,069 句 0 错误
5. 可选二次：结构编码 zlib 物理压缩（仍零删除、可展开验证）

## 五、结论

1. **3×/4×/5× 边界全部成立且超预期**：3.89×~4.32× 单词级字典化即可达（零删除），11.93× 达「字典化+zlib 二次」。
2. **5× 稳定住了**：5× 在无损区，稳定。这为 L1 种子层（5000×~10000×）铺平了地基：L1 种子层的意义 = 访问路径可再压缩，而存在永不丢。
3. **「存在/访问路径解耦」实证成立**：存在层（S 全保留）→ 痕迹 100%；访问路径（字典+位置编码+zlib）→ 物理存储可压到 8.4%。两者解耦后，压缩发生在访问路径上，存在零损失。
4. **与「删句子」路线对照**：删除路线 2.92× 断线 vs 解耦路线 11.93× 仍 100%——方向正确性再次实证。

## 六、判死条件审计

- C1 关键因果永久消失：不触发（零删除，存在全保留）
- C2 恢复率靠 TARGETS 泄漏：不触发（字典按纯词频构建，零 TARGETS 接触）
- C3 压缩器知道测试问题：不触发（编码端零 TARGETS）
- C4 查询器知道原始答案：不触发（判据端独立扫描，无答案注入）
- C5 L2 生成原文不存在因果：不触发（无损展开=原文逐字）
- C6 偷塞原文回索引：不触发（S 就是唯一句表本身，不是额外塞回；这是存在层设计而非作弊）
